# AlgoLatch v0.1.1-preview.2 for macOS and Windows

> **Testing preview:** this release fixes the workbench height and resizing
> regression found after `v0.1.1-preview.1`. Some courses may still contain
> interaction, layout, localization, animation, or result bugs. If you find
> one, open a
> [GitHub issue](https://github.com/Ice-teapop/algolatch/issues/new/choose) and
> include the course number, operating system, display scale, reproduction
> steps, and a screenshot. Do not post private source code, API keys, or
> exploitable security details in a public issue.

This prerelease provides two unsigned packages built and verified from the same
source revision:

- `AlgoLatch-0.1.1-preview.2-unsigned-universal.dmg` for Apple Silicon and
  Intel Macs;
- `AlgoLatch-Setup-0.1.1-preview.2-unsigned-x64.exe` for Windows 10/11 x64.

## What changed

- Removed the large unexplained blank area below the workbench in tall windows.
- Let the primary canvas and code workspace absorb the remaining height only
  after the runtime pane reaches its configured maximum.
- Aligned pointer and keyboard resizing with the actual rendered pane size.
- Kept dynamic splitter limits and ARIA values synchronized as the window
  changes size.
- Corrected lesson-strip and workbench grid ownership so hidden course chrome
  does not reserve an empty row.
- Added a tall-window Electron regression that verifies every meaningful
  workbench region reaches the same bottom edge and that blocked reverse drags
  do not jump.
- Made the M6-M8 Electron regression load the current Vite source rather than a
  stale renderer build.

## Known preview limitations

- The expanded course surface remains under active testing. Individual courses
  can still have animation timing, text overlap, responsive layout,
  localization, task-validation, or result defects.
- The macOS application is ad-hoc signed, not Developer ID signed or notarized.
- The Windows installer is not Authenticode-signed. Windows can display an
  unknown-publisher or SmartScreen warning.
- Some course scenes use bounded teaching models because the verified Trace
  boundary proves executed lines and branches but does not sample arbitrary C
  variables.
- The workbench remains a single-`main.c` application. Macros, `goto`, parser
  recovery, and partial CFG regions can reduce structured editing capability.

## Installation and verification

Download only from this GitHub Release and verify `SHA256SUMS.txt`.

### macOS

1. Download the Universal DMG and `SHA256SUMS.txt`.
2. Run `shasum -a 256 --check SHA256SUMS.txt` in the download directory.
3. Open the DMG and copy **AlgoLatch** to **Applications**.
4. If Gatekeeper blocks this unsigned preview, Control-click the app, choose
   **Open**, and approve it once. Do not disable Gatekeeper globally.

### Windows

1. Download the x64 EXE and `SHA256SUMS.txt`.
2. Verify the installer with `Get-FileHash` before opening it.
3. Run the one-click per-user installer. No administrator access, external
   compiler, gateway script, or `PATH` change is required.

Replacing or uninstalling the application does not remove managed projects in
Documents. API credentials and application state remain in the operating
system user profile.

## Release gates

- Release-boundary, notice, formatting, type, dependency, unit, integration,
  architecture, and Electron regression checks.
- macOS Universal build, ad-hoc signature validation, DMG installation,
  launch, and application probe.
- Windows locked-toolchain build, real installation, launch, native C
  compile/run, uninstall, and project-retention checks.
- Independent platform manifests followed by one public SHA-256 manifest over
  the final DMG and EXE.
